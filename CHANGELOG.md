# Changelog

## [1.0.0] – 2026-06-10

### Added

- Initial standalone extension.
- Explicit Patch, Restore, Status, and Refresh Status commands.
- Status bar state for C/C++ Tools Proxy.
- Automatic update check on startup (configurable via `CpptoolsProxyPatcher.autoCheckUpdates`).
- Manual **Check for Updates** command.
- Bundled pinned `cpptools-proxy` release artifacts with SHA-256 verification.
